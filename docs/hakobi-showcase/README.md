## 再生成

必要なPythonパッケージは `python-docx`、Pillow、pypdfです。WordからPDFへの書き出しには、既存の技術レポートと同じLibreOfficeを使います。`HAKOBI_SOFFICE`で場所を指定でき、未指定時は`docs/hakobi-report/tools/update_toc_pages.py`の候補から探します。

```powershell
python docs/hakobi-showcase/tools/build.py --pdf
python docs/hakobi-showcase/tools/package.py
```

本文を変えたときはPDFの全ページを画像にし、欠落、読みにくい画像、説明と画面の食い違いを確かめます。資料の6つの節をそれぞれ1ページにしています。Wordのヘッダー・フッターと本文は編集可能です。

画面を撮り直す場合は、リポジトリの依存が入った環境で次を実行します。

```powershell
node docs/hakobi-showcase/tools/capture.cjs
```

撮影はOSの一時フォルダにWebをビルドし、独立したDBとサーバーを起動して行います。運用中のDB・サービス・`dist-web/`は変更しません。デモの日付は2026年10月21日を基準としているため、別の日に撮影する場合は日程も見直してください。使用したソースのコミットと表示条件は `assets/capture-info.json` に残します。
