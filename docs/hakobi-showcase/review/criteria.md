# HAKOBI 紹介資料の評価基準

対象読者は、HAKOBIを初めて見るチームのメンバーとリーダーです。資料の目的は、仕事で使う場面と利点が伝わり、小さく試す判断ができることです。

| 評価項目 | 配点 | 確かめること |
|---|---:|---|
| 冒頭の分かりやすさ | 20 | 何をするツールで、何に役立つかが冒頭で分かる |
| 自分の仕事とのつながり | 20 | 自分のチームで使う具体的な場面を想像できる |
| 進捗共有と相談の魅力 | 20 | 状況が分かること、相談しやすくなる理由が伝わる |
| 画面と使い方 | 20 | 画像が説明に対応し、どこを見てどう使うか分かる |
| 試す意欲と最初の一歩 | 20 | 試す理由があり、使い始めるための行動が分かる |

各項目は、0〜7点が説明不足、8〜11点が大きな疑問が残る、12〜15点が理解できるが改善の余地がある、16〜18点が具体的で分かりやすい、19〜20点が疑問なく自分の仕事に置き換えられる状態とします。目安は合計80点以上かつ各項目12点以上です。目安に届くよう点数を調整せず、理由と本文の該当箇所を示してください。

点数とは別に、以下に答えてください。

1. 自分のチームで使ってみたいですか。理由は何ですか。
2. 特に役立ちそうな場面はどこですか。
3. 導入をためらう点、分かりにくい点は何ですか。
4. 読後、最初に何をすればよいと理解しましたか。

読者の立場での評価と、実際の製品仕様の正誤は分けます。効果の測定や人による利用者調査の代わりにはなりません。初回の評価は残し、改善後も同じ基準で再評価します。前回の点数を超える義務はありません。
