# HAKOBIの試用を準備する方へ

この資料は、紹介資料を読んで試用を相談された方に向けた案内です。参加者と、試したい仕事をひとつ決めてから準備すると、アカウントと最初のタスクを用意しやすくなります。

## すでにHAKOBIのサーバーがある場合

管理者が参加者のアカウントを発行し、社内LANから開ける接続先URLを伝えます。メンバーはブラウザでログインできます。デスクトップ版を使う場合は、そのサーバーの `/download` ページからインストーラーを入手できます。

## サーバーをまだ用意していない場合

アプリのソースと起動手順は [HAKOBIのリポジトリ](https://github.com/siroco-kyon/ToDo) にあります。社内LANで使うPC、データの保存先、アカウントを発行する管理者を決め、紹介セット内の「Web版の立ち上げガイド.md」に沿って準備してください。同ガイドの `D:\Github\ToDo` は配置先の例なので、実際に配置したリポジトリのフォルダで実行します。

チーム接続、サービス起動、バックアップ、メンバーへの配布は、紹介セット内の「HAKOBIのチーム接続と運用.md」にあります。

リポジトリ上の原本も参照できます。

- [Web版の立ち上げガイド](https://github.com/siroco-kyon/ToDo/blob/main/docs/web-setup-guide.md)
- [HAKOBIのチーム接続と運用](https://github.com/siroco-kyon/ToDo/blob/main/docs/HAKOBI.md)

## 先に個人用を試す場合

デスクトップ版を用意し、初回の接続設定で個人用を選びます。個人用は自分のPC内に保存するため、チーム用のサーバーは不要です。インストーラーを作る担当者は、リポジトリで `npm run dist` を実行して生成し、配布します。サーバーから配る場合は `npm run publish:desktop` の手順を使います。

## 最初の確認

参加者が同じ接続先でログインし、試す仕事を登録します。担当と期限を決め、メンバーが進捗ログを書き、別のメンバーが返信できることを確かめてください。次の定例で報告タブを開き、相談したいことを一緒に確認するところまでを試用の区切りにできます。

紹介セットの起動・運用ガイドは2026年10月21日時点のリポジトリから同封したものです。更新後に準備するときは原本も確認してください。
