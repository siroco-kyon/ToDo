## 通信図とGIF

team-traffic.svg のCSS/SMILは6秒周期。文字には動きを付けず、矢印上の光、箱の発光、アイコンの小さい移動に限定されている。途中のフレームを見ても文字位置は変わらない。

本評価者が独立して確認した内容:

- frames/000.png と frames/090.png のSHA256は同一。表示内容だけでなくPNGファイル自体が一致する。
- frames/030.png は異なるSHAであり、画像でも矢印上の光が途中へ進んでいる。
- 000、030、090の元サイズ画像を目視し、0秒と6秒が同じ構図・状態であることを確認。
- System.Drawingで成果物 team-traffic.gif のメタデータを読み、**90フレーム・合計6000ms・ループ値0（無限）**を確認。
- animation-check.json の「0秒と6秒のピクセル一致」「2秒時点差分」「90フレーム」「6000ms」「loop=0」と矛盾しない。

これにより、動きがあること、周期端が一致すること、6秒無限ループの成果物であることを静止画とファイルから確認できた。各閲覧ソフトでの再生速度や、すべてのフレームを連続再生した際の主観的な滑らかさまでは保証しない。OSの動きを減らす設定は、HTML/SVGの表示に影響し得る。検査スクリプトはno-preferenceを明示してフレームを生成している。
