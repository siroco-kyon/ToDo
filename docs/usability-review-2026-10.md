## 1. 用途と実際の動きのズレ（直したもの）

| 画面 | ズレ | 対応 |
| --- | --- | --- |
| タスク追加 | 一覧は既定で「担当: 自分」に絞られるのに、追加画面の担当の初期値は「未割り当て」。カテゴリを選んでいても追加時は「カテゴリなし」。追加したタスクが一覧から消えたように見えた | 担当は自分（一覧を特定の人で絞っていればその人）、カテゴリは左で選んでいるもの、開始日は今日を初期値にした。追加後に「開く」付きの通知を出し、絞り込みで見えないときは理由と「絞り込みを解除して開く」を出す |
| ガント | 日付のないタスクはチャートの下の「未配置タスク」に入り、スクロールしないと見えない | 開始日の初期値を今日にした。上部に「日付なし N件 ↓」を出し、押すと未配置の欄へ移動する |
| 報告タブ | 「担当: すべて」でも、左のタスク一覧の担当絞り込み（既定は自分）が先にかかり、定例で全員分が出なかった | 報告タブは一覧の担当絞り込みを使わず、報告タブ自身の担当絞り込みだけで決める（カテゴリ・検索の絞り込みは引き続き効く） |
| ガント・カンバンなど | タスク一覧を隠していると、一覧の絞り込みが効いていることに気づけない | 一覧の絞り込みが効く画面では、見出しの横に「絞り込み中 担当: 自分 ×」を出し、その場で解除できるようにした（1行を取らないよう、ガント・報告・概要は見出しの横、計画は日付の操作の横、見出しのないカンバンだけ列の上の細い1行） |
| 上部のタブ | 表示中のタブをもう一度押すと、タスク詳細の画面に切り替わっていた | もう一度押しても画面を変えない |
| カテゴリ | 「プライベート」は他の人からも見えるのに、名前とカンバンの🔒で隠れるように見えた。「すべて表示／共有集計」の切り替えは、集計外カテゴリが1つもなくても常に出ていた | 「集計から外す（個人用。ほかの人にも見えます）」「集計外」に統一。切り替えは「すべて表示／集計外を隠す」とし、集計外カテゴリがあるときだけ出す |
| タスク詳細 | 進捗ログに返信・いいねが出ず、報告タブでは見える返信に気づけない | 報告タブと同じ表示（返信・いいね・要相談・編集・削除）にした |
| タスク詳細 | 「完了にする」ボタンがない。状態・担当・期限などは「編集」を開かないと変えられない | 「✓ 完了にする／完了を取り消す」を置き、状態・優先度・カテゴリ・担当・日程をその場で変えられる欄を追加 |
| タスク詳細 | サブタスクの担当を表示・変更できない（報告タブ・ガントではできる） | 担当の表示、追加時・編集時の担当選択を追加（初期値は親タスクの主担当） |
| カンバン | 列の追加欄で、日本語変換を確定する Enter でタスクが作られる | 変換中の Enter では追加しない |
| 進捗タブ | 投稿欄の初期選択が一覧の先頭タスクで、別のタスクに誤投稿しやすい | 前回投稿したタスク（なければ未選択）から始め、選択肢を「自分の担当／ほかのタスク／完了」に分けた。選ぶまでは入力欄を無効にする |
| 全体 | 用語のゆれ（期限／締切、進捗ログ／進捗メモ）。メモと進捗ログの違いが説明から読み取れない | 「期限」「進捗ログ」に統一。説明＝目的（あまり変わらない）、メモ＝今の状況（上書き）、進捗ログ＝日付つきで積み上がる報告、と説明を書き分けた |
| タスク一覧 | 絞り込みで隠れているだけでも「タスクがありません／最初のタスクを追加」と出る | 「絞り込み条件に合うタスクはありません」と「絞り込みを解除」を出す |

## 2. 見やすさ・入れやすさの工夫

- 報告タブ
  - 件数チップ（すべて・報告なし・要相談・保留中・期限超過・期間中に延期）を押すと、そのタスクだけに絞る。チェックボックスの列を減らした
  - 担当者別（カテゴリ別）のときは「担当者へ移動」の目次を出し、人ごとの件数と報告なしの数が分かる。見出しごとに折りたためる
  - 自分の担当で未報告のタスクがあると、上部で知らせ「自分の未報告だけ表示」できる
  - 期間に「今週」「先週」（月曜始まり）を追加
  - 今日以降に始める未着手タスクは「報告なし」にしない（作ったばかりのタスクが赤くならないように）
- タスク追加
  - Enter で追加、Shift+Enter で改行（複数行は1行ずつ別タスク）
  - 期限は「今日・明日・金曜・1週間後・なし」のボタンでも選べる（日付も表示）
  - 内容・メモ・状態・優先度は「詳しく設定」に畳んだ
  - ガントのカテゴリ（担当者）見出しの「＋ 追加」から、そのカテゴリ（担当者）で追加できる。ガントが空のときも「＋ タスクを追加」を出す
- ガント
  - 保留ボタンは、保留中のタスクだけ紫の「▶（再開）」を常に出し、それ以外の行はマウスを乗せたときだけ灰色の「Ⅱ」を出す
  - 未配置タスクの「P3」表記をやめ、優先度が高いものだけ「優先度 高」と出す
- タスク一覧: 期限を「10/15・あと2日」「今日まで」「3日遅れ」のように残り日数で出す。担当の絞り込みで「自分」を先頭にした
- 上部のタブにホバーで用途の説明を出す。「今日のレール」は中の見出しと同じ「今日の予定」に改名
- 操作ボタン付きの通知（元に戻す・開く）は少し長めに出す

## 4. 進捗タブを使いたくなる工夫（2026-10-14 追加）

- **新着の印と件数**: 前回進捗タブを見たあとに、ほかの人が書いた投稿・返信に「新着」「新しい返信」の印を付ける。上部の「進捗」タブにも件数を出す（サーバー版のみ。見た時刻はユーザーごとに端末へ覚える）
- **件数チップ**: すべて／新着／自分宛て（自分の投稿・返信への返信、「@自分」のメンション）／自分の担当タスク／要相談／まだ反応なし（ほかの人の投稿で返信もリアクションもないもの）
- **区切りの見出し**: 新しい順・古い順では「今日 10/14（水）」「昨日」などの日付、タスク別・カテゴリ別・投稿者別ではその名前で区切る。スクロールしても上に残る
- **@メンションの候補**: 進捗ログ・返信の入力で「@」を打つとメンバーの候補が出る（↑↓で選んで Enter）。自分は候補に出さない。進捗タブ・報告タブ・タスク詳細で共通
- **メンションの判定を日本語の書き方に合わせた**: 以前は「@」の前が行頭か空白のときしか通知されず、「〜しました。@佐藤」では届かなかった。メールアドレスの一部でなければ拾い、「@佐藤さん」「@佐藤へ」のような敬称・助詞が続く書き方も拾う（「@佐藤健」は「佐藤」にしない）
- **リアクション**: 👍 に加えて 🎉 おめでとう・👀 見ました・🙏 ありがとう を「☺＋」から付けられる。通知の文言も絵文字に合わせた（👍 はこれまでどおり「いいね」）
